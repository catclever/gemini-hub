# Command: /sync2gdrive

## 功能说明
当用户输入 `/sync2gdrive` 或要求同步文件到 GDrive 时触发。该指令会自动推断需要同步的最小目录范围，并基于当前项目根目录执行同步脚本。

## 执行 SOP

1. **确定同步范围 (Minimize Scope)**
   - 分析用户传入的参数（如果有）或当前的对话上下文（如刚刚生成的模型输出目录、检查点等）。
   - 选择出**最小、最精确需要同步的目录列表**，避免全量同步不必要的文件。

2. **定位项目根目录 (Set CWD)**
   - 确认当前项目的工作区根目录（Workspace Root）。
   - **关键要求**：命令执行时，必须将该根目录作为当前工作目录（CWD）。脚本内部会通过 `$(basename "$PWD")` 来作为云端目标文件夹名称。

3. **调用同步脚本 (Execute)**
   - 使用系统的 `run_command` 工具执行该全局脚本。
   - 传入的参数必须是相对于项目根目录的相对路径。
   ```bash
   # 在项目根目录下执行
   /Users/kael/Library/Scripts/sync2gdrive <选定的相对目录1> [目录2...]
   ```

4. **结果验证与反馈 (Verify & Report)**
   - 检查脚本的输出，确认是否成功在云端建立了对应目录，并在本地建立了软链接。
   - 向用户汇报同步成功的具体目录以及操作结果。
