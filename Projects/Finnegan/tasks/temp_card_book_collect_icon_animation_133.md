# 临时卡片收集按钮图标升级为翻开的书与加页动效

## 任务目标与背景
优化临时卡片收集按钮（转正）：移除文字标签，将原先类似下载的箭头图标升级为优雅的“翻开的书”SVG 图标，并在悬停（hover）时触发书页飞入/滑入书中的加页动效，增强将漂浮灵感收入典籍的隐喻与仪式感。

## 变更概述
1. **移除文字标签**:
   - 彻底移除了临时卡片收集按钮内的 `<span>收集</span>` 文字，转为纯净、极简的圆形纯图标按钮。
   - 散落悬停（scattered）态为 `26px × 26px` 圆形悬浮胶囊；聚焦模态（focused）态为 `32px × 32px` 圆形按钮。
2. **“翻开的书”典籍隐喻图标**:
   - 废除原先易被误认为“下载”的下箭头收纳盒图标，替换为精心设计的 SVG 展开书卷（`book-spine-cover` 与雅致书页肌理线 `book-pages`）。
3. **Hover 往里加页动效（`page-settle`）**:
   - 按钮内嵌独立动效图层 `.adding-page`。
   - 常态下加页处于隐匿微浮状态（`opacity: 0`）；
   - 悬停（hover）触发时，新书页以真实的物理纸张微弹曲线（`cubic-bezier(0.34, 1.45, 0.7, 1)`）从右上方滑入册中，柔和倾斜并严丝合缝地归位落入展开的书页间，生动呈现“将飘散灵感归入典籍”的优雅仪式感。
4. **测试与构建验证**:
   - 前端 180 个自动化单元测试全部通过。
   - Vite 生产构建 0 报错通过。
