# 2026-09-21 Syntax Error (The "Blame" Incident)

## 错误还原
- **现象**: 在注入透明背景脚本时，控制台持续报出 `SyntaxError: Invalid or unexpected token`。起初误认为是缓存问题或是 TaiChi 热更机制的缺陷。
- **真相**: 实际错误发生在另一个独立文件 `web/custom_panel.js` 的第 832 行：`const key = Object.keys(el).find(k => k.startsWith('__reactFiber));`（遗漏了单引号）。
- **为何形成“背锅”误区**: 
  - 该语法错误在此次任务开始前就已被引入。
  - 由于开发者在此前并未刷新页面，该错误处于“潜伏”状态。
  - 直到应用“透明背景”代码并指示开发者刷新重载页面时，浏览器对所有文件进行第一次完整重新解析，引爆了 `custom_panel.js` 的语法错误。
  - 由于错误在 `import()` 时被拦截抛出，且发生的时间点正好处在测试“透明背景”这一步，导致问题原因被严重误判。

## 教训
- 当遇到模块加载报错时，必须第一时间排查**所有相关联的文件**的语法正确性（使用 `node -c` 等工具），而不是想当然地认为是新引入模块或缓存的问题。
