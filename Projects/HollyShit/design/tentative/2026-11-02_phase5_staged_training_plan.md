# Phase 5 分阶段训练方案：单流右脑 → 采择器 → （以后）伴飞流

## 0. 用户确认的原则
1. **先训没有伴飞流的单流右脑。** 确定性完全由主干流决定。
2. **风格是隐式条件**，由较长的上下文流（或以后的伴飞流）决定。**禁止任何风格标签输入**；来源标签只用于分组日志/评测。
3. **知识采择器独立训练**，候选池先用"上文子句"（自监督），与右脑单/多流无关。
4. **伴飞流以后再做**，定位偏"指令遵循/持续条件"（指令约束、角色、目标、参考文档），以零初始化附加分支接入，冻结主干。
5. 数据不偷懒：新语料要完整段落/真证据/难负例（但需先实测数据源）。

## 1. 左脑诊断结论（#031，Colab 实测 N=72）
| 条件 | Edit Sim | Entity Recall |
|---|---|---|
| A 相关吸引子 | 95.74% | 96.05% |
| B 纯无关吸引子 | 92.93% | 88.26% |
| C 无吸引子 | 94.58% | 91.77% |
| D 1 相关 + 3 无关 | 95.01% | 94.86% |
- 不重训左脑。B < C ⇒ 采择器必须有"不抄/空选项"，没有相关候选时传 `k_attractors=None`。
- `OrthogonalAttractor` 的 SnapGate 在无关输入上也饱和（MaxSim≈0.58 ≫ 0.08），过滤靠采择器而不是左脑。
- 部分错字源自编码器/翻译器往返（π→0、沃→奋），不是左脑问题。

## 2. 阶段一：单流右脑（Stage 1）
- **主干流 = 上文前缀子句 + 目标子句**，只对目标行计算损失（`target_mask`）。
  - 问答：前缀 = 多轮历史（若有）+ 问题全部子句（含材料行）；目标 = 回答子句。
  - 续写：从同一篇长文随机截取连续 T 个子句；前若干行为上下文，其余行均为目标。
- **T 默认 32 子句**（原 8），每子句 L=32 字。
- **停笔**：问答——未截断时最后回答行=1，其余回答行=0；被截断时窗口内回答行全为 0（真实结尾在窗口外）。续写——`stop_valid=False`，不参与停笔损失。
- 问答 / 续写按 `--cont_ratio` 混合，按来源分组记录损失与 σ。
- 沿用 #029：K 路盲推演 65/35、频带 NLL 先验（σ_max 默认 3.0）、高频抖动、计划自采样。
- **为阶段三预留零初始化**：`alpha_aux` 初始化为 0；PriorHead 中消费伴飞特征（F_aux、gate_max、gate_sum）的输入权重零初始化。保证无伴飞流时输出与阶段一完全一致，以后接伴飞流不会随机扰动。
- 评测：问答/续写滚动生成 + 停笔；多解演示；**σ 随上下文长度曲线**（同一续写样本只给前 2/4/8/16 子句，看下一步 σ 是否下降——隐式条件的直接证据）；按模块计时。

## 3. 采择器（独立训练，可与阶段一并行）
- 候选池 = 主干流中目标行之前的所有子句（以后可并入外部知识子句）。
- 探针 = 目标子句真值向量 + 噪声；可选混入右脑采样的 `z_thought`（阶段二微调）。
- 标签 = **IDF 加权的稀有片段重合**（只认低频字二元组/数字/拉丁词，过滤"的是""我们"等高频片段）；**sink（不抄）标签** = 没有任何候选达到阈值。
- 推理：sink 概率高或全部低于阈值 → 不给吸引子（条件 C）；否则 top-M。
- 注意：混合 batch 中部分样本无吸引子时，左脑 `k_mask` 全 False 可能产生 NaN，必须处理。

## 4. 阶段三（以后）：伴飞流
- 冻结阶段一，只训伴飞流 Mamba、门控与先验/条件修正项（零初始化），数据需"指令与内容分离"。数据源待调研。

## 5. 数据
- 立即可用：现有 omni 语料（问答，材料在 prompt 前几行）、任何 `{"text": ...}` 长文 JSONL（续写）。
- 待实测：长文（中文维基、网文、知乎）、知识对话（DuConv/KdConv）、DuReader 原版、CMRC2018 完整段落。调研报告里的 HF 名称/规模/许可均未验证。

## 6. 风险
- 频带"低频=语义"仍是假设，靠 σ 分组日志验证。
- 续写配比过高可能带偏回答口吻；靠隐式上下文 + 后段提高问答比例 + 评测样例监控。
- IDF 伪标签对改写型复用召回偏低。
