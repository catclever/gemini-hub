# 修复文件编辑中文乱码(Base64加号还原+分块组装解码+IME优化)

## 任务目标与背景
解决在编辑过程中出现的中文乱码问题：
1. 修复前后端 Base64 传输因 URL 查询参数中加号(+)被解析为空格导致的字节流移位乱码；
2. 修复后端 write_chunk 逐块解码 UTF-8 导致跨分块多字节中文字符被截断为替换字符(U+FFFD)的问题，改为先拼装完整 Base64 再整体解码；
3. 后端 read 动作增加 UTF-8 带 BOM 兼容与 GBK/GB18030 自动降级探测，解决非标准 UTF-8 中文文件打开即乱码；
4. 前端输入优化：加入 IME composition 组合态生命周期管理，输入拼音汉字期间临时恢复文字可见度且暂缓高亮重绘，汉字上屏后恢复；
5. 编辑器样式增加 PingFang SC / Microsoft YaHei 中文字体显式声明，确保 textarea 与 pre 汉字字形与光标像素级一致。
